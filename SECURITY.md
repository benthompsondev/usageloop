# Security

Please report suspected security vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/benthompsondev/usageloop/security/advisories/new).
Do not open a public issue for a security problem.

Never put credentials, tokens, auth files, private Codex prompts or responses,
conversations, or unrelated logs in a public issue. For ordinary app problems,
use the [problem report form](https://github.com/benthompsondev/usageloop/issues/new?template=bug_report.yml).
