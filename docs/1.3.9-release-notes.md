# UsageLoop 1.3.9: Chinese support and clearer quota

Draft for approval. Publish only after the checks in the
[maintainer checklist](maintainer-checklist.md) pass. Remove this draft notice
and checklist link from the final GitHub release body.

UsageLoop now supports Simplified Chinese in the same Windows/Linux app.
Choose English, Simplified Chinese, or your system language in Settings, then
fully exit and reopen UsageLoop. Thanks to **hefengq** for the localization,
language selection, documentation and tests in PR #4.

Both green quota bars now show **remaining allowance**, following the suggestion
in Issue #3 from **Th1n-Snow**. The labels still show consumed percentages.
Unknown readings stay unchecked. Readings whose reset time has passed ask you
to sync rather than pretending the allowance has refilled. The last-sync label
also uses the latest quota check, rather than an older clock confirmation.

Chinese midnight and early-morning times keep their leading zeroes, and weekly
controls keep stable internal identifiers in either language.

Scheduling, weekly protection, read-only Sync and duplicate-request safeguards
are unchanged. An unconfirmed start still cannot be retried merely because
quota appears available. Issue #2 remains under investigation pending details
from its reporter; this release does not claim to fix that report.

UsageLoop uses a small amount of your existing Codex allowance to start the
normal next five-hour window. It does not add quota, bypass limits, or resume
coding tasks. Your computer must be awake, signed in and running UsageLoop at
the scheduled time.
