# UsageLoop 1.4.0: Six languages and updates in About

Release candidate. This version has not been published.

Open **About** to see the installed version, update status and manual update
controls at the top. Download and install actions appear there when applicable.
Release notes sit below the action buttons, so longer notes do not hide the next
step on a small screen.

Returning to About brings Updates back into view. Keyboard users can tab from
About directly to the update action. The dashboard's model-support shortcut
also opens the right page and starts one manual check.

Download and Not now stay next to each other in keyboard order. The dashboard
shortcut keeps an existing check, download or verified installer in place.

If a read-only check confirms a running window after an uncertain start, the
dashboard and tray now show both facts: the clock is running, and the earlier
start remains unconfirmed. Recent starts keeps the original outcome and no-retry
protection. The timestamp verifier and scheduling rules are unchanged.

Formatted update errors now translate correctly in Chinese, including HTTP
status and Linux archive-rejection messages. A catalogue coverage test guards
literal translation calls. The copied technical summary keeps its English
identifiers and now separates quota state from the last start outcome.

Settings keeps language, scheduling, sign-in startup and Codex diagnostics.
Choose English, Simplified Chinese, Spanish, Brazilian Portuguese, French or
Japanese in Settings, then fully exit and restart. Language choices persist
independently of scheduling and automation. Unknown text falls back to English.
The four new catalogues are generated translations with engineering checks;
native-language review has not been performed.

Narrow windows stack cards and weekly editors so translated controls remain
readable. Japanese uses system font fallbacks; Linux CI installs Noto CJK for
glyph validation. No new network service or translation dependency is added.
Thanks again to **hefengq** for contributing Chinese support in 1.3.9.

Update checks still run only after a click. Downloads still require checksum
verification, and installation still requires confirmation. Windows and Linux
keep their existing installation paths. Schedules, history, weekly protection,
read-only Sync and the rule against retrying uncertain requests are unchanged.

The Windows upgrade matrix now includes the published 1.3.9 installer.
It checks settings, history, automation state and the selected language before
launching with automation disabled in the disposable fixture. Packaged acceptance
opens the actual Dashboard, Settings and About pages in all six languages.
Linux UI checks use X11 under Xvfb; they do not establish real desktop or tray
integration. Native-speaker validation of the four new languages remains open.

Japanese scheduling copy now explicitly requires the PC to stay awake. The
French first-start button explicitly says it acts now. Linux install confirmation
describes the archive and restart rather than a Windows setup window.

A reproducible Windows Qt IPC teardown crash is covered by a regression test.
Socket signals now use context-bound slots instead of callbacks retaining the
socket and its owner. The process mutex and scheduler ownership are unchanged.
See the [release verification record](1.4.0-release-verification.md) for evidence
and the remaining publication steps.
