# UsageLoop 1.4.0: Updates in About

Draft for local development. This version has not been published.

Open **About** to see the installed version, update status and manual update
controls at the top. Download and install actions appear there when applicable.
Release notes sit below the action buttons, so longer notes do not hide the next
step on a small screen.

Returning to About brings Updates back into view. Keyboard users can tab from
About directly to the update action. The dashboard's model-support shortcut
also opens the right page and starts one manual check.

Settings keeps language, scheduling, sign-in startup and Codex diagnostics.
English and Simplified Chinese remain available, with updated copy and previews.
Thanks again to **hefengq** for contributing Chinese support in 1.3.9.

Update checks still run only after a click. Downloads still require checksum
verification, and installation still requires confirmation. Windows and Linux
keep their existing installation paths. Schedules, history, weekly protection,
read-only Sync and the rule against retrying uncertain requests are unchanged.

The Windows upgrade matrix now includes the published 1.3.9 installer.
Candidate CI, installer acceptance and Linux desktop verification remain pending;
see [the development review](1.4.0-development-review.md).
