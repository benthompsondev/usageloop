# UsageLoop 1.4.0: Six languages, easier updates, clearer status

UsageLoop now supports six interface languages: English, Simplified Chinese,
Spanish, Brazilian Portuguese, French and Japanese. Choose **Settings → Language**,
then fully exit and reopen the app to apply your choice. The four newly added
languages use generated translations with automated review; they have not had
native-speaker review.

Updates are now at the top of **About**, beside the installed version and update
status. Checks and downloads remain manual and do not consume Codex allowance.
Installation still needs your confirmation.

The dashboard can show a running five-hour window while keeping an earlier
start marked as unconfirmed. A running window does not prove that UsageLoop
started it. The conservative checks for confirming starts and the safeguards
against retrying uncertain requests are unchanged.

This release also improves keyboard navigation, layouts in smaller windows,
translated messages and app reliability. Your settings, history, automation
preferences and chosen language are preserved during an upgrade.

**Upgrading from 1.3.9?** Open **Settings → Updates** to check for 1.4.0, then
download and install after verification. After upgrading, find future updates
in **About**.

Thanks to **hefengq** for the Simplified Chinese support introduced in 1.3.9.
