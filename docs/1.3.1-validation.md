# UsageLoop 1.3.1 verification

The trigger now prefers GPT-5.6 Luna over Codex's general default. It intersects
a short reviewed preference list with the live catalog, excludes hidden,
superseded and non-text models, and selects the lowest advertised reasoning level.
GPT-5.4 mini is the only fallback, and only while the catalog still considers it
current. Unknown successors and expensive general defaults are refused.

The catalog has no comparable quota prices. The preference list therefore needs
review when the lightweight lineup changes. Standard service is requested
explicitly. The prompt asks for only OK and no tools. Recent starts exposes the
model and reasoning already saved for each attempt; no history migration is needed.

## Completed checks

- 453 tests passed, including scheduling, weekly protection, reservations,
  post-send no-retry behavior, selection, pagination and historical metadata.
- Compile, CLI/desktop entry-point checks and the Windows executable build passed.
- Live Codex 0.153.1 model/list resolves to gpt-5.6-luna / low. This runtime does
  not advertise none for Luna; the broader API effort list is not substituted.
- A single empty ephemeral thread accepted the model and standard-service
  parameters. No turn/start was called.
- A copy of existing 1.3.0 settings and history loaded without modification and
  rendered its saved model/reasoning. Original user files were untouched.

## Release gates

The installer matrix now includes an explicit 1.3.0 upgrade case. Packaging,
disposable Windows installation acceptance and an installed-app check must pass
before release. Installer and installed-app results belong with the release
evidence; the local checks above do not substitute for them.

No quota-consumption experiment was run. The next natural scheduled start after
installation should confirm Luna/low in Recent starts, a verified reset, and the
post-start allowance before other Codex work. Whole-percent display and delayed
accounting limit measurement precision. Savings are expected, not measured.

The trigger still waits for its bounded lifecycle result before independent
multi-sample anchor verification. App-server supports turn/interrupt, but does
not document an early event guaranteeing window activation and reduced billing
after cancellation. This patch adds no cancellation or output-inspection path.
